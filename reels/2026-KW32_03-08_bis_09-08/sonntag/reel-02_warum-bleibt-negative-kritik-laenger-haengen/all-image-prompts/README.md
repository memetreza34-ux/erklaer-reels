# Alle Bildprompts

`all-image-prompts.txt` ist die verbindliche Google-Flow-Sammeldatei.

Direkt bei **jedem** Prompt stehen:
- Bildnummer
- Ziel (Cover/Szene)
- exakter Dateiname
- Einzelbild-Anweisung

Google Flow darf erst zum nächsten Prompt wechseln, nachdem das aktuelle Bild fertig erzeugt und sofort umbenannt wurde.
