# Nummerierter Bild-Schnellimport

Dieser Ordner wird erst verwendet, wenn die komplette Bildreihe fertig erzeugt und jedes Bild bereits korrekt benannt ist. Bevorzugter Standard: `Bild 00.png` = Cover, `Bild 01.png` = Szene 1, `Bild 02.png` = Szene 2 usw. Kompatibilitätsnamen wie `00.png`, `bild-00.png`, `bild_02.webp` oder `03-meine-szene.jpg` werden ebenfalls erkannt. Die Dateinummer bestimmt nur das vorgeschlagene Ziel; vor der endgültigen Übernahme muss jedes Bild weiterhin visuell geprüft werden.
