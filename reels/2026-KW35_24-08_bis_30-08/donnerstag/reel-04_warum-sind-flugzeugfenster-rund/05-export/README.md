# 05 – Export

Nach dem finalen Render soll dieser Bereich alles enthalten, was direkt zum Hochladen benötigt wird:

```text
FERTIGES-REEL.mp4
UNIVERSELLE-CAPTION.txt
```

Die MP4 wird lokal beim Rendern erzeugt und deshalb nicht in Git gespeichert. Die Caption wird automatisch aus `caption/caption.txt` in den Export übernommen.
