# Roadmap

## Phase 1 – Grundlage

- [x] Repository initialisieren
- [x] Produktionsregeln dokumentieren
- [x] Wochen- und Reel-Ordner automatisch erstellen
- [x] stabile Szenen-IDs und Asset-Manifest anlegen
- [x] Grundstruktur validieren

## Phase 2 – Script- und Szenenagent

- [ ] Thema oder fertiges Script einlesen
- [ ] Hook und Verständlichkeit prüfen
- [ ] Script auf 35–55 Sekunden optimieren
- [ ] 8–10 sinnvolle Bildmomente erzeugen
- [ ] passende Bildwelt begründet auswählen
- [ ] jede Szene als strukturiertes JSON speichern

## Phase 3 – Bildprompt-Agent

- [ ] englische Prompts aus dem Szenenplan erzeugen
- [ ] deutsche Schlüsselwörter sinnvoll im Bild platzieren
- [ ] Figuren- und Stilkontinuität absichern
- [ ] Cover-Prompt separat erzeugen
- [ ] Prompt-Qualitätsprüfung hinzufügen

## Phase 4 – Audio und Bilder

- [ ] austauschbaren Audio-Provider anbinden
- [ ] Voice-over-Datei und Metadaten speichern
- [ ] austauschbaren Bild-Provider anbinden
- [ ] Szenenbilder und Cover erzeugen
- [ ] einzelne fehlerhafte Assets gezielt neu generieren

## Phase 5 – Qualitätskontrolle

- [ ] Vollständigkeit automatisch prüfen
- [ ] Script, Szene, Prompt und Bild logisch vergleichen
- [ ] unlesbaren oder falschen Bildtext erkennen
- [ ] Stilabweichungen innerhalb des Reels melden
- [ ] Freigabestatus und Review-Bericht erzeugen

## Phase 6 – Später

- [ ] Remotion-Animationen
- [ ] automatischer Videoschnitt
- [ ] Untertitel nur optional
- [ ] fertiges MP4
- [ ] Social-Media-Veröffentlichung
