==================================================
WRITTEN STYLE LOCK — SERIOUS MINIMAL COUNTRYBALL
==================================================
Serious Minimal Countryball Explainer visual world, exactly matching the Reel visual DNA and adapted only to a horizontal 16:9 YouTube canvas. Clean, serious, premium flat 2D countryball explainer. Perfectly round ball characters when an actor is useful, simple white eyes, thick clean black outlines, controlled flat colors, restrained soft graphic shading, adult and informative, never childish or goofy.

No normal illustrated humans. No humanoid cartoon people. No stick figures. No photorealism. No realistic human scenes. No glossy 3D. No Pixar. No clay. No anime. No busy icon collage.

==================================================
PREMIUM DESIGN LAYER V1 — HARD LOCK
==================================================
Premium means BETTER DESIGN INSIDE THE SAME COUNTRYBALL WORLD, never a style change.
For every image use clear visual hierarchy, meaningful scale contrast, deliberate 16:9 balance, purposeful overlaps, elegant flat foreground/midground/background layering when useful, one coherent palette with one dominant base color and one or two controlled accents, intentional negative space, clean typography, and maps/borders/routes that are simplified but elegant and instantly readable.
Prefer relationships over object lists. Avoid random centering, weak empty backgrounds, generic icon grids and repeated layouts.
Clean does NOT mean empty. Minimal does NOT mean lifeless. Premium does NOT mean realistic.

==================================================
VISUAL STORYTELLING HARD LOCK
==================================================
Use visual relationships such as before→after, center→periphery, group→border→outsider, crown→people, fragmented→unified, foreign control→self-rule, attachment→political claim, inclusion→exclusion and idea→consequence. Every image must communicate one clear idea within about one second.

==================================================
ADAPTIVE IMAGE DENSITY V3 — HARD LOCK
==================================================
There is NO fixed target image count as a global rule. This project contains 28 images because the narration has 28 distinct visual purposes. One image = one clear visual purpose. Complex ideas were split instead of overloaded. Preferred average hold is about 4.5–7.5 seconds. No filler images.

==================================================
ANTI-LIFELESS HARD LOCK
==================================================
Avoid tiny isolated subjects lost in huge empty backgrounds, meaningless icon collages, mechanically repeated centered-countryball layouts, flat rows of unrelated symbols, or the same map repeated without a new information step.

==================================================
DEUTSCH-HARD-LOCK
==================================================
Every readable word must be German. English visible text or pseudo-text = HARD FAIL. If a prompt says no visible text, generate no readable text.
