# Edit-, Motion- und SFX-Plan

Voice-over ist Timing-Master. Die A–E-Zeiten sind Phase-1-Ziele; finale Schnitte kommen aus `FINAL_TIMELINE.json`.

## Motion-Rotation
- A/B: einfacher `slow push-in` oder ruhiger Pan, keine unnötige Bewegung.
- C: `slow push-in`, `gentle pan` oder subtile Parallaxe abhängig von Leserichtung.
- D: langsamer Karten-/Szenen-Pan oder sehr subtiler Pull-back, damit mehrere Elemente lesbar bleiben.
- E: nahezu ruhiger Start, danach sehr langsamer Push, damit die Übersicht 12–15 s lesbar bleibt.
- Keine zwei aufeinanderfolgenden Bilder mit exakt identischer Motion, wenn eine sinnvolle Alternative möglich ist.

## Geplante SFX
- Bild 01: subtiler Low-Impact beim Hook-Reveal.
- Bild 05: sehr leise entfernte Kampf-/Unruhe-Atmosphäre.
- Bild 12: sehr leise Huf-/Steppenbewegung.
- Bild 13: Fluss + leise Wagenbewegung.
- Bild 15: kurzer entfernter Battle-Swell, keine harten Treffer.
- Bild 21: Winterwind + entfernte Bewegung.
- Bild 23: kurzer Tor-/Stadt-Impact + entfernte Menge.
- Bild 25: Hafenambience + sehr dezenter Low-Impact.
- Bild 27: Meer + kurzer gedämpfter Battle-Swell.
- Bild 31: einzelnes leises Metall-/Stoffgeräusch beim Insignienwechsel.
- Bild 35: subtiler Zusammenfassungs-Impact.
- Bild 38: sehr leise Wind-/Straßenatmosphäre, danach sauber auslaufen.

Alle anderen Bildwechsel standardmäßig ohne SFX. Keine Musik. Kein SFX darf das Voice-over überdecken.
