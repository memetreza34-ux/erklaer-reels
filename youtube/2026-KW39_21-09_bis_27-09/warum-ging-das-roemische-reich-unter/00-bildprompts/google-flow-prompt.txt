==================================================
MASTER STYLE LOCK — SERIOUS MINIMAL COUNTRYBALL EXPLAINER
==================================================

Use the exact active Reel visual DNA, adapted only to a 16:9 horizontal YouTube canvas:
clean serious minimal 2D countryball explainer, perfectly round ball characters when an actor is useful, simple white eyes, thick clean black outlines, flat controlled colors, minimal soft graphic shading, low-to-medium controlled detail, one dominant focal subject, zero to three meaningful supporting props, simple solid or muted background with optional subtle texture or gradient, strong symbolic storytelling, instantly readable, adult informative tone, not childish.

HARD NEGATIVES:
no stick figures, no human-head characters, no humanoid cartoon people, no normal illustrated humans, no realistic humans, no realistic hands or skin, no detailed realistic rooms, no cinematic full-scene realism, no photo backgrounds, no mixed media, no glossy 3D, no Pixar, no clay, no anime, no manga, no stock-photo aesthetic, no busy icon collage, no tiny decorative countryballs, no random tongue or gag faces, no watermark.

COUNTRYBALL HARD LOCK:
- ball body is a perfect circle/sphere, never oval, bean-shaped or egg-shaped
- no separate human head
- simple white eyes with controlled expression
- optional tiny simple arms/hands/feet only when action requires them
- flag patterns only when geography/politics/cultural identity is genuinely relevant
- for ancient/historical groups without a modern flag, use neutral or historically suitable solid colours plus one simple identifying prop/symbol; never invent a modern national flag
- if an object, symbol or map explains the point more clearly, no countryball is required

COMPOSITION HARD LOCK:
- one dominant focal subject
- usually 0–3 meaningful supporting elements
- allowed modes: Minimal Symbolic, Supported Explainer, Simple Mini Scene
- backgrounds stay simple and graphic
- historical content must be translated into this same reduced Countryball visual language, not into realistic historical paintings

==================================================
DEUTSCH-HARD-LOCK — JEDER SICHTBARE TEXT
==================================================

This is a GERMAN project. Every readable word visible anywhere in every generated image MUST be German.

This applies to:
- headlines
- map labels
- oceans and seas
- city/region labels
- signs
- legends
- diagrams
- arrows/callouts
- calendars
- UI-like elements
- background text

Do NOT automatically generate English map labels. Do NOT generate pseudo-text or fake writing.
If text is not explicitly needed, generate NO TEXT rather than inventing labels.
Any English visible text = HARD FAIL and the image must be regenerated.
Any pseudo-text/unreadable text = HARD FAIL and must be removed or regenerated.

Examples:
ATLANTIC OCEAN = forbidden → ATLANTISCHER OZEAN
MEDITERRANEAN SEA = forbidden → MITTELMEER
BLACK SEA = forbidden → SCHWARZES MEER
WEST / EAST = forbidden → WEST / OST
ROMAN EMPIRE = forbidden → RÖMISCHES REICH
