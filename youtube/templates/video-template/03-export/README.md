# YouTube Export — vier Dateien

- `FERTIGES-VIDEO.mp4` – fertiges Video ohne Cover
- `THUMBNAIL.png` – eigenständig generiertes Cover, erscheint nicht im Video
- `YOUTUBE-UPLOAD.txt` – Titel, vollständige Beschreibung und Caption in einer Datei
- `YOUTUBE-UNTERTITEL-ZEITABSCHNITTE.txt` – kompletter Sprechertext mit echten Zeitstempeln

Keine zusätzlichen Titel-, Beschreibungs-, Kapitel- oder Tags-Dateien. Kapitel können innerhalb der Beschreibung erwähnt werden, bekommen aber keine eigene Datei.
