==================================================
WRITTEN STYLE LOCK — SERIOUS MINIMAL COUNTRYBALL
==================================================

Serious Minimal Countryball Explainer visual world, exactly matching the Reel visual DNA and adapted only to a 16:9 YouTube canvas. Clean serious minimal flat 2D countryball explainer. Perfectly round ball characters when an actor is useful, simple white eyes, thick clean black outlines, controlled flat colors, restrained soft graphic shading, adult and informative, never childish or goofy.

No normal illustrated humans. No humanoid cartoon people. No stick figures. No photorealism. No realistic human scenes. No glossy 3D. No Pixar. No clay. No anime. No busy icon collage.

==================================================
PREMIUM DESIGN LAYER V1 — HARD LOCK
==================================================

Premium means BETTER DESIGN INSIDE THE SAME COUNTRYBALL WORLD, never a style change.

For every image:
- create one dominant focal subject with clear visual hierarchy
- deliberately balance the 16:9 canvas; avoid random centering
- use meaningful scale contrast
- use purposeful overlaps and layering
- when helpful, create simple foreground / midground / background depth using flat 2D layers
- use one coherent main palette with normally one dominant base color and one or two controlled accent colors
- use negative space intentionally, not as empty unused space
- integrate arrows, routes, borders, documents and symbols into a single composition instead of listing icons
- make maps simplified but elegant, legible and spatially clear
- if text is requested, treat typography as part of the composition with strong hierarchy and clean spacing
- vary composition mode, direction, scale and placement between adjacent images

The result should feel polished, premium and art-directed while remaining unmistakably Serious Minimal Countryball Explainer.

Clean does NOT mean empty. Minimal does NOT mean lifeless. Premium does NOT mean realistic.

==================================================
VISUAL STORYTELLING HARD LOCK
==================================================

Prefer relationships over object lists. When relevant, visualize:
- before → after
- cause → effect
- divided → connected
- route → border → obstacle
- attack → counter-movement
- center → periphery
- system A → system B
- old border → new border

If a countryball actor is used:
- perfectly round body
- simple white eyes
- thick clean black outline
- restrained expression
- tiny simple limbs only when needed for the action
- no hair, neck, realistic hands or realistic face

If a map, object or symbol explains the point more clearly, a countryball is not mandatory.

==================================================
ADAPTIVE IMAGE DENSITY V3 — HARD LOCK
==================================================

There is NO fixed target image count.
One image = one clear visual purpose.

Split into an additional image when the narration introduces:
- a new core idea
- cause and then consequence
- before and after
- a new place, era or perspective
- a new actor
- a separate border/map/route step
- a separate number/data idea
- a switch from explanation to example
- a simple scene that would otherwise stay on screen too long

Preferred average hold: about 4.5–7.5 seconds.
Review any planned hold above 9 seconds.
Strongly prefer a meaningful split above 11 seconds.
Global hard maximum: 16 seconds.
Do not add filler images without a new visual idea.
Do not repeat the same map or composition with only tiny cosmetic changes.

Complex information should be split across multiple elegant images rather than crammed into one overloaded frame.
