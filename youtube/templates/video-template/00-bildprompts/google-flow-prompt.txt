==================================================
WRITTEN STYLE LOCK — SERIOUS MINIMAL COUNTRYBALL
==================================================
Serious Minimal Countryball Explainer visual world, exactly matching the Reel visual DNA and adapted only to a 16:9 YouTube canvas. Clean serious flat 2D countryball explainer. Perfectly round Countryball actors when an actor is useful, simple white eyes, thick clean black outlines, controlled flat colors, restrained soft graphic shading, adult and informative, never childish or goofy.

No normal illustrated humans. No humanoid cartoon people. No stick figures. No photorealism. No realistic human scenes. No glossy 3D. No Pixar. No clay. No anime.

==================================================
SCENE ILLUSTRATION V2 — HARD LOCK
==================================================
THIS VIDEO MUST LOOK LIKE A SERIES OF CLEAR ILLUSTRATED SCENES, NOT LIKE ABSTRACT INFOGRAPHIC POSTERS.

Prefer:
- a recognizable place, institution, environment or situation tied to the spoken idea
- Countryballs visibly doing something when actors are useful
- one clear action or relationship per image
- environmental context around the main idea
- simple foreground / midground / background depth
- scene-specific props integrated naturally into the environment
- varied but controlled scene colors

Avoid as the default:
- abstract symbol boards
- presentation-slide layouts
- split-panel infographic posters
- multiple boxed explanations
- rows or grids of icons
- giant diagram arrows floating in empty space
- tiny Countryballs surrounded by labels
- one static object centered on an empty background

Use infographic structure only when the spoken idea genuinely cannot be shown as a concrete scene. Even then, show one relationship, not a dashboard.

==================================================
TOPIC VISUAL RELEVANCE V1 — HARD LOCK
==================================================
EVERY IMAGE MUST MATCH BOTH THE CURRENT SPOKEN SENTENCE AND THE SPECIFIC VIDEO TOPIC.

Before writing each image prompt, answer internally:
1. What exactly does this sentence mean inside THIS topic?
2. Which place, institution, object, conflict, actor, historical detail or situation is specific to THIS topic?
3. Could this exact image be dropped into a different explainer with almost no change? If yes, it is too generic and must be redesigned.

Mandatory:
- every Bild NN has a written `Topic Anchor:` in the image plan
- the Topic Anchor names the concrete topic-specific element that makes the image belong to this video
- prefer topic-specific institutions, objects, places, documents, historical situations and actions over generic metaphors
- generic metaphors are allowed only when no clearer topic-specific scene exists
- arbitrary countries, flags or national Countryballs are forbidden
- a country/flag may appear only when that country is actually part of the narration or historically necessary for the exact point
- do not use Germany, France, USA or any other country merely to make a generic concept look political
- the final image must summarize the core topic itself, not end on a generic moral that could fit another video

Example logic:
Bad: two random national Countryballs at a crossroads to represent "freedom with limits".
Better for a Liberalismus video: Countryballs moving freely through a civic street while constitution, court and legal boundaries visibly protect equal freedom.

==================================================
PREMIUM DESIGN LAYER V1 — HARD LOCK
==================================================
Premium means BETTER DESIGN INSIDE THE SAME COUNTRYBALL WORLD, never a style change.

For every image:
- create one dominant focal subject with clear visual hierarchy
- deliberately balance the 16:9 canvas; avoid random centering
- use meaningful scale contrast
- use purposeful overlaps and layering
- when helpful, create simple foreground / midground / background depth using flat 2D layers
- use one coherent main palette with normally one dominant base color and one or two controlled accent colors
- use negative space intentionally, not as empty unused space
- integrate arrows, routes, borders, documents and symbols into a single composition instead of listing icons
- make maps simplified but elegant, legible and spatially clear
- if text is requested, treat typography as part of the composition with strong hierarchy and clean spacing
- vary composition mode, direction, scale and placement between adjacent images

The result should feel polished, premium and art-directed while remaining unmistakably Serious Minimal Countryball Explainer.

Clean does NOT mean empty. Minimal does NOT mean lifeless. Premium does NOT mean realistic.

==================================================
VISUAL STORYTELLING HARD LOCK
==================================================
Prefer relationships over object lists. When relevant, visualize before→after, cause→effect, divided→connected, route→border→obstacle, institution→rule→effect, or one concrete action leading to another.

If a Countryball actor is used:
- perfectly round body
- simple white eyes
- thick clean black outline
- restrained expression
- tiny simple limbs only when needed for the action
- no hair, neck, realistic hands or realistic face

If a map, object or institution explains the point more clearly, a Countryball is not mandatory.

==================================================
ADAPTIVE IMAGE DENSITY V3 — HARD LOCK
==================================================
There is NO fixed target image count.
One image = one clear visual purpose.

Split into an additional image when the narration introduces:
- a new core idea
- cause and then consequence
- before and after
- a new place, era or perspective
- a new actor
- a separate border/map/route step
- a separate number/data idea
- a switch from explanation to example
- a simple scene that would otherwise stay on screen too long

Preferred average hold: about 4.5–7.5 seconds.
Review any planned hold above 9 seconds.
Strongly prefer a meaningful split above 11 seconds.
Global hard maximum: 16 seconds.
Do not add filler images without a new visual idea.
Do not repeat the same map or composition with only tiny cosmetic changes.

Complex information should be split across multiple elegant images rather than crammed into one overloaded frame.
