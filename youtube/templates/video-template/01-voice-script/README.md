# 01 – Voice-Script — V2

Für neue YouTube-Projekte gibt es hier **genau ein vollständiges Skript**:

```text
voice-script.txt
```

Keine sichtbaren Script-Parts, keine 10er-Pakete und keine zusätzlichen Nutzerdokumente.

Phase 1 legt die Bildwechsel intern über `99-technik/BILD_AUDIO_ZUORDNUNG.json` fest. Jeder Bildmoment besitzt dort einen exakten `startAnchor` und `endAnchor` aus diesem Gesamtskript sowie seine A–E-Komplexitätsklasse.

Die genaue Schnittzeit wird erst in Phase 3 aus dem echten finalen Voice-over gemessen.
